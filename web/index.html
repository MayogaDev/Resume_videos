Características Principales

Transcripción con Whisper

Utiliza OpenAI Whisper para transcripciones precisas en múltiples idiomas con detección automática.

Resumen Inteligente

Modelo mT5 entrenado específicamente para generar resúmenes concisos y coherentes en español.

Métricas ROUGE

Evaluación automática de calidad usando métricas ROUGE-1, ROUGE-2 y ROUGE-L.

Exportar Resultados

Descarga transcripciones y resúmenes en formatos TXT y JSON para uso posterior.

Configuración Avanzada

Ajusta parámetros como longitud del resumen, modelo Whisper, beams, y más.

Procesamiento Rápido

Optimizado para GPU con soporte CUDA para procesamiento en tiempo récord.
